# Archive

This directory preserves historical artifacts that remain relevant for context
but are no longer part of the active codebase.

- `patches/` stores legacy patch files that informed prior refactors.
- `tasks/` contains frozen task and issue snapshots for provenance.

Refer to [docs/history/](../docs/history/) for curated narratives and to the
[CHANGELOG](../CHANGELOG.md) for a chronological view of shipped changes.
