# Documentation Hub

All project documentation lives in this directory. Start with
[`index.md`](index.md) for an annotated map of architecture references, runbooks,
message schemas, and reports.

Curated subdirectories:

- [`architecture/`](architecture/) — system diagrams, data flow descriptions,
  and runtime deep dives.
- [`guides/`](guides/) — playbooks for automation, support, and operational
  tasks.
- [`reports/`](reports/) — post-incident write-ups, operations reports, and
  analytics snapshots.
- [`history/`](history/) — archived narratives preserved for provenance.

Cross-cutting references include the [specification](SPEC.md), the
[API reference](API.md), the [style guide](STYLE-GUIDE.md), and the living
[task list](TASKLIST.md).
